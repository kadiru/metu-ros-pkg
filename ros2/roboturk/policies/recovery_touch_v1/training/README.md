On cross schedules the team owning the confirmed recovery receives the opening return. Mirrored selection rows above include every scheduled start for that candidate. The development audits and all historical diagnostics retain unconfirmed openings. The qualification table counts all 40 starts on every attempt.

The two main carrier families use observed roller displacement and velocity, or match roller velocity to the ball before a retreat or lateral carry. The additional experiments tested forecasting the moving opponent’s roller and blending lateral motion into the existing shared-ball maneuver. Every scoring and custody decision uses the same physical audit.
